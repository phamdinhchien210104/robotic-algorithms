# Bộ lưu trữ kết quả đối sánh (Comparation)

Thư mục này lưu trữ toàn bộ các kết quả thực nghiệm, hình ảnh trực quan hóa, biểu đồ và số liệu đối sánh theo các chỉ tiêu định lượng được xác định trong `Định hướng.md`:

1. **Thời gian xóa vết vật cản ảo (Ghost Track Duration):** So sánh số chu kỳ quét / thời gian để triệt tiêu bóng ma giữa Baseline và Thuật toán cải tiến.
2. **Bộ nhớ RAM chiếm dụng (Memory Footprint):** So sánh mức tiêu hao bộ nhớ (MB) giữa mảng 2D tĩnh toàn cục và cấu trúc lưới thưa (Sparse Grid).
3. **Thời gian tính toán mỗi frame (Latency ms/frame):** Đo độ trễ xử lý trên dữ liệu thực tế và giả lập nhằm chứng minh khả năng đáp ứng thời gian thực (Real-time).
